# 三十年人生計畫 v2（Life Plan 1978–2056）

單檔網頁的人生規劃系統：願景告示板、使命任務對應、48 年回顧、30 年四階段藍圖、年／週／日計畫、七大領域目標。
資料在瀏覽器端用你的密碼加密（PBKDF2 + AES-256-GCM），自動同步到 **另一個私人 GitHub 倉庫**。

## 架構：兩個倉庫

| 倉庫 | 公開/私人 | 開 Pages？ | 放什麼 |
|---|---|---|---|
| 網頁倉庫（例：`lp-k7x2`） | Private | **開** | `index.html`、`README.md`（只有程式，沒有你的資料） |
| 資料倉庫（例：`my-life-data`） | Private | **不開** | `lifeplan.enc.json`（加密資料，系統自動寫入） |

別人就算知道網頁網址，也只看得到一個要密碼的鎖定畫面；資料倉庫是私人的，連加密檔都拿不到。

## 部署步驟（約 15 分鐘）

1. **GitHub Student Developer Pack** 已啟用（帳號有 GitHub Pro，私人倉庫才能開 Pages）。
2. **建網頁倉庫**：New repository → 取一個不好猜的名字（例 `lp-k7x2`）→ Private → 建立。
   Add file → Upload files → 上傳 `index.html`、`README.md` → Commit。
   Settings → Pages → Source：`Deploy from a branch`，Branch：`main` / `(root)` → Save。
   約 1 分鐘後得到網址：`https://你的帳號.github.io/lp-k7x2/`
3. **建資料倉庫**：New repository → 名稱例 `my-life-data` → **Private** → 勾選 **Add a README file** → 建立。不要開 Pages。
4. **建 Token**：右上頭像 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
   - Repository access：**Only select repositories** → 只選 `my-life-data`
   - Permissions → Repository permissions → **Contents：Read and write**
   - Expiration：建議 1 年（到期前 GitHub 會寄信提醒，再產生一組貼上即可）
   - 產生後複製（只會顯示一次）
5. **開始使用**：打開 Pages 網址 → 建立密碼 → 「設定 → 雲端同步」填帳號、`my-life-data`、Token → 按 **連線並同步**。
   右上角顯示「已同步 HH:MM」就完成了。

## 自動同步怎麼運作

- 打開網頁、解鎖後：自動下載雲端最新版本。
- 修改後約 45 秒、切換分頁 / 關掉分頁 / 按上鎖時：自動上傳。
- 切回這個分頁時（超過 1 分鐘）：自動檢查別台裝置是否更新過。
- 離線時：先存在本機，連上網路後自動補傳。
- 右上角的圓點：綠＝已同步，橘＝待同步／同步中／離線，紅＝失敗或衝突。點一下可立即同步。
- 兩台裝置都改了同一份：會跳出提示，讓你選「用雲端版本」或「用這台的版本覆蓋雲端」，不會自己蓋掉。
- 每次上傳都是一個 commit，資料倉庫的 History 可以找回任何舊版本。

## 換新裝置（手機、另一台電腦）

打開 Pages 網址 → 展開「換新裝置：從 GitHub 私人資料倉庫載入」→ 填帳號、資料倉庫、Token → 輸入密碼。
之後這台裝置會記住設定（Token 加密存在本機，不會上傳）。

## 安全與備份

- **密碼無法找回**。系統不保存密碼，忘了就沒人能解開。請寫在紙上收好。密碼建議 12 字以上。
- **Token 等於資料倉庫的鑰匙**，不要貼到其他地方；外流時到 GitHub 刪掉那組 Token 即可。
- **每月下載一次備份**：設定 → 備份與還原 → 產生加密備份 → 下載。總覽頁超過 30 天沒備份會提醒。
- 閒置 20 分鐘自動上鎖（上鎖前會先同步）。
- 網頁程式裡只有通用的範例文字，沒有任何個人資料。

|---|---|

| 願景 | 2056 願景宣言、使命宣言、核心價值、願景告示板（卡片＋圖片＋使命任務＋連結目標）、對應表 |

| 回顧 1978–2026 | 四個問題、各年代大事記 |
| 30 年藍圖 | 重建／深耕／轉換／傳承四階段、年齡對照表 |
| 年計畫 | 年度主題、各領域年度成果、到期目標、年終回顧 |
| 週計畫 | 三顆大石頭、待辦、週日回顧 |
| 日計畫 | 三件最重要的事、時間區塊、習慣、感恩、反思 |
| 目標 | 健康／家庭／金錢／旅遊興趣／社交／學習／事業 |

**願景 → 使命任務 → 目標** 的關係：願景是 30 年內要實現的畫面；使命任務是為了它要持續做的事；目標是可以衡量進度的里程碑。卡片進度＝連結目標平均進度與任務完成率的平均。
